Project plan
Project idea
This project is about creating a to-do list application for people to manage their everyday tasks more efficiently.

Planned features

Feature 1 Add the task you aree going to do.
Feature 2 Click the task if you completed it.
Feature 3 Show All / Completed / Incompleted tasks with filter features.

How to use the application:
Type the task in the span, and click "Add" button. The task will then show in the list below, you can click it when it is done, and delete it by pressing the trash bin icon on the right.
In the bottom, it shows the tasks remaining.


Open the published application using the link above.
Fill in the form fields.
Add, edit, remove or mark items as completed.
Refresh the page and check whether data remains available in the browser, if you used localStorage.
Running the application locally
Clone or download this repository to your computer.
Open the project folder.
Open index.html in a web browser.
